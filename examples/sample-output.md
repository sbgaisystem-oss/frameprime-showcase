# Approved Output Policy

このディレクトリには、公開権利と安全性が確認された成果物だけを掲載します。

実際の画像・動画を追加する前に、最低限次を確認します。

```text
SOURCE KNOWN
RIGHTS CONFIRMED
PRODUCTION RESULT CONFIRMED
NO PRIVATE DATA
NO SECRET
NO CUSTOMER DATA
```

## Do not publish by default

- Service Smokeで使用したSource動画
- 顧客・テスター由来の動画
- private X / SNS投稿
- 内部検証Evidence
- 権利確認前の音源・画像・フォント・ブランド素材

## Review rule

「Productionで生成できた」ことと「Public Showcaseへ掲載できる」ことは別判定です。公開権利が確認できない素材は掲載しません。

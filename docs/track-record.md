# 実績・検証結果

FramePrimeで**実際に確認できたこと**を日付・件数・条件つきでまとめます。確認できていないことは「未確認」「未集計」と書きます。

最終更新：2026-11-28 ／ 現行製品Version：v0.0.4

## 読み方

| 区分 | 意味 |
| --- | --- |
| 運営による本番検証 | 運営が本番環境で実際の登録・購入・生成・納品・精算を行って確認したもの（一般ユーザーと同じ権限のアカウントでの確認を含みます） |
| 隔離環境での試験 | 本番と切り離した試験環境で確認したもの。本番での発生や回復を示すものではありません |
| 一般の利用者による利用 | 運営と関係のない利用者による利用の実績 |
| 第三者による検証 | 外部の人・組織による確認やレビュー |

各項目は個別の素材・アカウント・条件での記録です。全素材での成功・処理時間・成果を保証するものではありません。

同じ59分51秒・883字幕の英日Dual作品で、従来の全尺再出力15分46.9秒、差分初回3分46.0秒（76.1%短縮）、文字配置キャッシュ利用1分49.9秒（88.4%短縮）を本番確認。出力予約から納品READYまで。各回の修正箇所・内容は異なり、従来は文章2件・時刻2件、差分各回は文章2件のみ。キャッシュ利用時は変更区間約27秒のみ再描画、未変更映像99.25%の圧縮データと音声全体の一致を確認しました。対応条件内の少数字幕修正が対象で、条件外は従来の全尺描画です。速度保証ではありません。

現行の通常の修正版出力は元動画と最新の完成動画を保持し、新しい修正版が正常に納品された後に旧完成版を整理します。以前の完成版が必要な場合は出力前に保存してください。過去の修正版共存例は当時の仕様です。

各Revisionの完了・保存と追加0 Creditsを確認しました。変更字幕の画像サンプルと全字幕の結合・完成ファイル照合に基づく検証で、全尺独立目視ではありません。

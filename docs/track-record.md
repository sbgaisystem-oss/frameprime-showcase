# 実績・検証結果

FramePrimeで**実際に確認できたこと**を日付・件数・条件つきでまとめます。確認できていないことは「未確認」「未集計」と書きます。

最終更新：2026-11-27 ／ 現行製品Version：v0.0.4

## 読み方

| 区分 | 意味 |
| --- | --- |
| 運営による本番検証 | 運営が本番環境で実際の登録・購入・生成・納品・精算を行って確認したもの（一般ユーザーと同じ権限のアカウントでの確認を含みます） |
| 隔離環境での試験 | 本番と切り離した試験環境で確認したもの。本番での発生や回復を示すものではありません |
| 一般の利用者による利用 | 運営と関係のない利用者による利用の実績 |
| 第三者による検証 | 外部の人・組織による確認やレビュー |

各項目は個別の素材・アカウント・条件での記録です。全素材での成功・処理時間・成果を保証するものではありません。

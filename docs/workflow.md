# Workflow

FramePrimeの基本フローは次のとおりです。

```text
つくる
  ↓
投稿準備
  ↓
投稿
  ↓
記録
  ↓
学ぶ
  ↓
次を伸ばす
```

## 1. つくる

動画素材を受け取り、制作フローを開始します。字幕などの処理は、最終成果物を作るための品質Gateを通過しながら進みます。

## 2. 投稿準備

完成動画を確認し、必要ならStudioで修正します。投稿先に応じた文章など、投稿前の準備もここで行います。

## 3. 投稿

FramePrimeは、すべてのSNSへの自動投稿を前提にしていません。SNSごとに対応している導線とユーザー自身で行う操作を分離します。

## 4. 記録

投稿した動画をFramePrime内の記録と結びつけます。取得可能な場合は投稿後KPIもEvidenceとして保存します。

## 5. 学ぶ

Growthでは、実測KPIと動画構造を分離して扱います。未取得・非対応の指標を0として補完しません。

## 6. 次を伸ばす

改善提案はEvidenceへ紐づけ、次回は一度に多くを変えすぎず、比較可能な変更を積み重ねることを重視します。

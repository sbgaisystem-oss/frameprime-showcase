## はじめての方へ — よくある10の質問

### 1. FramePrimeとは何ですか？

動画を入れると字幕入りの完成動画とSNS投稿文がそろうAI動画制作OS（Webサービス）です。難しい編集操作もプロンプトも要りません。手元の動画か対応するX動画URLから始めます。仕上がりを確認してご自身でSNSへ投稿します。

### 2. CapCutやVrewとは何が違いますか？

使いみちが違います。CapCutやVrewは自分の手で細かく作り込める動画編集ソフトです。自動字幕などのAI機能も備えています。FramePrimeでは動画を入れたあとの字幕づくりと投稿準備をAIがまとめて進めます。作り込みたい一本は編集ソフトで。早く出したい一本はFramePrimeで。使い分けや併用ができます。他社製品の機能や料金は各社の公式情報をご確認ください。[比較表](../README.md#一般的な動画編集ソフト汎用aiとの違い)

### 3. ChatGPTやClaudeを直接使う場合とは何が違いますか？

進め方が違います。ChatGPTやClaudeなどの汎用AIは字幕文や投稿文を書くのが得意です。ツールやコードを組み合わせれば動画の加工もできます。FramePrimeは取り込み・生成・確認・対応する修正・投稿準備までを1つの専用画面にまとめています。指示文やツールの組み合わせを自分で考える必要がありません。優劣ではなく任せ方の違いです。

### 4. 動画編集の知識やプロンプトは必要ですか？

要りません。動画を選び字幕モードと投稿先を選んで生成を始めるだけです。仕上がりの確認はご自身で行い直したいところは簡易版かPC専用Studioで直せます。

### 5. どのようなユーザーに向いていますか？

- 編集は初めてでまず1本を字幕つきで仕上げたい方
- 話す動画をSNSへ続けて出したい方
- 編集より撮ることや話すことに時間を使いたい方
- 日本語・English・韓国語の翻訳字幕や2言語字幕を付けたい方
- プロンプトやAIツールの組み合わせを考えたくない方

### 6. どのような用途には向いていませんか？

- カット割り・BGM・エフェクトなどを自分で細かく作り込む編集（一般用途の動画編集ソフトの代わりを目指すものではありません）
- SNSへの自動投稿・投稿代行
- YouTube・TikTok・InstagramのURLからの直接取り込み（動画ファイルのアップロードをご利用ください）
- 270分または入力400MBを超える動画
- スマートフォンだけでの細かな編集（StudioはPC専用です）
- 利用する権利のない動画の加工

### 7. 無料でどこまで利用できますか？

本人確認済みの新規登録で10 Creditsを受け取れます。入力2分以内の動画は1本1 Creditなので10本分です。完成後の対応する修正・再書き出しと動画と一緒に作るSNS投稿文は追加0 Credits。翻訳字幕は2分まで無料プレビュー（0 Credit）で確かめられます。新規登録特典・現行新プランのCreditに有効期限はありません。旧Founder β月額の既存契約は別です。登録にはメール認証が必要です。すべての素材での制作成功を保証するものではありません。

### 8. 完成動画の修正に追加料金は必要ですか？

対応する修正・再書き出しは追加0 Creditsです。Creditを使うのは新しく動画を生成するときだけです。2026年11月23日に字幕1か所を修正して再書き出しとダウンロードを行い追加消費0を本番で確認しています（字幕修正の例です。すべての編集種類・端末を確認したものではありません）。

### 9. SNSへの自動投稿はできますか？

できません。FramePrimeが用意するのは投稿用の動画と文章までで投稿はご自身の手で行います。SNSのログイン情報をお預かりすることもありません。

### 10. 投稿後の改善機能とは何ですか？

投稿した結果を記録して振り返り次の動画で変える点を整理する機能（Growth）です。いま使える範囲は限られています。

- **提供中：** 投稿の記録と取得できた数値の確認。数値の自動取得はXの一部（対応する期間）に限られます。取得できなかった数値を0として扱うことはありません。
- **停止中：** Geminiによる補助的な映像内容分析。
- **開発中：** 修正した内容や投稿結果を学び次の制作へ反映する仕組み。提供時期は未定です。

公開できる利用者の改善実績はまだありません。再生数などの成果を保証する機能ではありません。確認できた実績と未確認の項目は[実績・検証結果](track-record.md)にまとめています。

対応するX動画URLを入力できますが、URL入力後にも投稿先など必要な項目を選び、生成を開始して完成物を確認する操作が必要です。URLコピーだけで全工程が完了するサービスではありません。手元の動画ファイルからも始められます。

## SNS投稿文やハッシュタグを作るとCreditsを消費しますか？

**動画生成時に付随するSNS投稿文・ハッシュタグの準備は追加0 Creditsです。** 投稿文を作成する・しないによって動画制作の消費Creditsは変わりません。入力動画2分以内の新規動画制作は1 Creditです。**投稿文だけを新規作成する単独機能は現在提供していません。** 旧β版の「投稿準備パッケージ単位で1 Credit」は現行仕様ではありません。過去の投稿準備履歴は閲覧できます。

## 動画1本に何Creditsかかりますか？（Original Voice）

**標準配置のMP4ファイル入力は最大270分・400MBまで（36分超は長尺試験提供）です。料金は入力実尺2分以内なら1 Creditです。** 料金契約上の計算は、2分超〜8分なら2 Credits、8分超〜12分なら4 Credits。以降も入力動画が4分長くなるごとに2 Credits追加します（32分=14 Credits、32分超〜36分以内=16 Credits、最大270分=134 Credits）。**完成後の動画尺ではなく、入力動画の実際の長さ**が基準です。買い切りの通常単価なら1 Creditは100円相当ですが、プランによって単価は変わります。表示・内部台帳とも整数Creditに統一します。**この料金体系は2026年11月21日に適用済みです。** 長尺の数字は料金の計算例であり、その長さの動画を制作・納品できることの保証ではありません。 通常のsystem terminal failureはreservationが解放され、net 0 user creditsです。

## Creditの購入方式は？

正式な月額は **2,900円/32、5,800円/70、9,800円/125、19,800円/260 Credits** です。買い切りは **1,000円/10、3,000円/30、6,000円/60、10,000円/100 Credits**。別枠のβ体験980円/20 Creditsは生涯1回・自動更新なし。すべて税込で、現行新プランのCreditは期限なし・繰越可能です。旧Founder β月額の20 Creditsは次の請求期間開始時に失効し、既存契約は変更しません。詳細は[Credits and revisions](credits-and-revisions.md)。登録特典10 Credits・紹介報酬双方4 Credits（予算800 Credits）も新整数仕様です。3,000円買い切りの30 Creditsと紹介双方各4 Creditsは、2026年11月22日に限定した本番実証で付与を確認しています。購入・紹介の適用条件と、動画制作の通し検証状況は別です。

## 完成後の修正でもcreditを消費しますか？

対応する完成後の修正・再書き出し（Revision Render）は**追加0 Creditsという料金契約**です。新規生成とは区別します。あらゆる編集や新規再生成を無制限に無料とする意味ではありません。2026年11月23日には、認証済み利用者がPCの「字幕・動画を修正」から字幕1か所を保存し、修正版を再書き出し・ダウンロードして、追加Credit消費0を確認しました。これは字幕修正1例の実績で、すべての編集種類・端末を検証したものではありません。

## Geminiが動画そのものを作っていますか？

いいえ。**Gemini Video Analysis V2による補助的な内容分析は、2026年11月23日の本番設定確認では停止中です。** これは字幕作成・動画生成とは別の機能です。設計上は読み取り専用で動画を書き換えず、分析の失敗で生成・描画・納品を止めない境界を持ちます。

## 3秒HookはGeminiが決めていますか？

その説明は正確ではありません。完成動画の冒頭や画面変化などの構造データと、AIによる内容解釈を分ける設計です。Geminiの補助的な内容分析は現在停止中で、現在の動画制作の判断主体として説明しません。

## Geminiでは何を分析しますか？

**現在は停止中です。** 設計上の対象は、内容の要約、題材・価値の伝わりやすさ、実演の分かりやすさ、映像と発話の一致、情報量、結末の整合などです。現在の生成で必ず出力される分析結果として扱わず、将来の再生数を保証する予測値とも扱いません。

## Jev / JevBox / Cursor / HyperFramesはFramePrimeで何に使われますか？

役割は分かれています。Jevはdecision/evaluation provenance、JevBox-inspired Creative Memoryはsource-grounded retrieval、Cursorはdevelopment tooling、HyperFramesは一部の本番動画描画経路と、過去の品質評価系譜で利用します。すべての制作経路に必須という意味ではなく、ほかの各技術の役割も区別します。

## FramePrimeのEvidence-firstとは何ですか？

AIが書いた説明文そのものを事実の正本にせず、動画identity、時間範囲、観測Feature、観測KPI、source/provenanceへ戻れるEvidenceを優先する考え方です。

## Private Learningとは何ですか？

Global cross-user learningより先に、本人の過去動画・本人の実測KPI・本人の構造EvidenceからPersonal Baselineを作る方向です。Global corpus / vector / KG / cross-user learningは別Gateです。

## 字幕は単に生成するだけですか？

いいえ。FramePrimeは**coverage completeness**と**collision avoidance**を別の品質問題として扱います。また、source audio/transcriptの根拠が不足・曖昧な場合は、unsupported subtitleを創作で埋めるよりfail-closedを優先します。

## LangfuseはFramePrimeの判断を本番で直接変更しますか？

いいえ。Langfuse × Jev/P1のevaluation mirrorは **READ ONLY / NON-AUTHORITATIVE** として扱われ、production routingやoutput mutationのauthorityにはしません。

## MCPでFramePrimeを使えますか？

現時点ではProduction機能ではありません。Canonical architecture directionは **Dual Surface / Single Core** で、将来のMCP / Agent InterfaceもGUIと同じFramePrime Core、credit semantics、safety、ownership rulesへ収束させる方針です。

## Studioはスマホでも使えますか？

現在のStudioは **PC専用** です。スマートフォンでは別の簡易字幕修正画面を利用できます。PC専用Studio全体をスマートフォンで使えるという意味ではありません。

## Studioでは何ができますか？

Studioは今ある動画を仕上げるSurfaceです。現在の主な編集面は **Title / Thumbnail / Subtitles / CTA / Cut** で、対応するRevision Renderも含みます。一般目的のNLEを目指しているわけではありません。

## Growthは何のためにありますか？

Growthは、投稿後の実測KPI、動画側の構造Evidence、本人の過去投稿との比較から、**何が起きたか / なぜ起きた可能性があるか / 次に何を変えるか**を整理するためのSurfaceです。

## Growthは完成済みですか？

**Growth Core V1はProductionです。ただし全体はACTIVE_EXPANSIONです。** Xのexact-window KPI等のCurrent機能は動作していますが全SNS・全指標・全adapterが完成しているわけではありません。provider/API availabilityに依存しcross-platform coverageは拡張途中です。Gemini内容分析は停止中で比較できるデータが少ない場合は本人の傾向を断定しません。画面イメージの数値は利用者の成果実績ではありません。公開できる利用者の改善事例・集計値はまだありません。修正内容や投稿結果を学んで次の制作へ反映する仕組みは開発中です。

## FramePrimeのログイン方式は？

Currentは **passwordless email OTP** です。PWA / Home Screenでは6桁email OTPを使用します。PC browserでは既存のemail verification compatibilityも維持しています。

## なぜFramePrime独自のパスワードを使わないのですか？

Current design rationaleは、FramePrime独自のpassword credentialを増やさず、ユーザーが管理するcredential surfaceを小さくし、PWAでも低摩擦にログインできるようにするためです。これはemail OTPが全てのpassword/MFA設計より強いという意味ではありません。

## remembered emailにOTPやtokenも保存されますか？

いいえ。Remembered Email機能は最後に使ったemail addressを利便性のために保持しますが、**OTPとauth tokenはその機能ではpersistしません**。

## セキュリティ監査は完了していますか？

2026年10月12日に、対象を認証・認可・情報漏洩に限定した正式な事前監査は完了し、closure時点のCritical／Highは0件でした。ただし、これはSecurity Certificationではなく、後続のProduction変更・正式ローンチE2Eの成立を意味しません。

## Productionソースコードは公開されていますか？

いいえ。このRepositoryはDocumentation Showcaseです。Production source、internal prompt、credential、private infrastructure等は対象外です。

## 多言語字幕やNative appはありますか？

選択言語字幕・2言語同時字幕は現行のWeb制作画面で提供しています。Native appは将来の検討対象です。
